# ทดลองใช้ Lighthouse Dispatch v2 — ที่ประชุมวันอังคาร

## ส่วนที่ 1 · สำหรับ Gene (ผู้จัดประชุม)

### ก่อนวันประชุม (จันทร์เย็น หรือเช้าวันอังคาร)
1. **อัปเดตข้อมูลจากระบบเดิม:** เปิด Claude แล้วพิมพ์ "อัปเดตข้อมูล v2 จากระบบเดิม" Claude จะอ่านระบบเดิมผ่านเบราว์เซอร์ที่ล็อกอินไว้ (อ่านอย่างเดียว) แล้วนำเข้า v2 ข้อมูลล่าสุดตอนนี้คือ 23 ต.ค. 10:50 น.
2. **ทดลองเปิดเองก่อน 1 รอบ:**
   ```bash
   npm run trial
   ```
   หน้าจอจะแสดงที่อยู่ให้เปิดบนมือถือ (เช่น `http://192.168.x.x:3000/dev-login`) และ PIN
3. ลองเปิดที่อยู่นั้นบนมือถือของคุณเองที่ต่อ **Wi-Fi เดียวกับ Mac**
4. ถ้า macOS ถามว่าให้ "node" รับการเชื่อมต่อไหม ให้กด **Allow**

### วันประชุม
1. เสียบสายชาร์จ Mac แล้วรัน `npm run trial` คำสั่งนี้กัน Mac หลับให้ระหว่างที่รันอยู่
2. **เขียนที่อยู่บนกระดาน แต่ PIN ให้พูดเท่านั้น** ไม่ต้องเขียน
3. แจกส่วนที่ 2 ด้านล่าง (พิมพ์หรือส่งในกลุ่ม LINE ได้ เพราะไม่มี PIN อยู่ในนั้น)
4. หลังประชุมกด Ctrl+C เพื่อหยุดระบบ
5. ดูความเห็นทั้งหมดได้ที่แท็บ **ความเห็น** เมื่อเข้าใช้เป็นผู้ดูแล

### ทำไมงานจริงไม่พลาด
- v2 **ไม่เคยเขียนอะไรกลับไปที่ระบบเดิม** ระบบเดิมยังเป็นตัวจริง 100%
- งานที่สร้างใน v2 ช่วงทดลองไม่ใช่งานจริง ทุกหน้ามีแถบสีเหลืองบอกไว้
- ต้องมี PIN ถึงจะเข้าได้ คนที่ใช้ Wi-Fi เดียวกันแต่ไม่มี PIN เข้าไม่ได้ ถ้าใส่ PIN ผิดเกิน 10 ครั้ง ระบบจะล็อก 10 นาที
- ข้อมูลอยู่บน Mac เครื่องนี้เท่านั้น ไม่ได้ขึ้น cloud
- ก่อนเริ่มทดลอง Claude สำรองฐานข้อมูลไว้แล้ว

### ข้อจำกัดที่ควรรู้
- ข้อมูลลูกค้าเป็นข้อมูลจริง (สำเนา) ขอให้ทุกคนไม่ถ่ายภาพหน้าจอ
- หลายคนอาจใช้บทบาทเดียวกันพร้อมกัน ถ้ามีสองคนแก้งานเดียวกัน ระบบจะบอกคนหลังให้โหลดใหม่ ข้อนี้เป็นสิ่งที่ตั้งใจให้ลองดูด้วย
- เลขบัตรประชาชนช่างยังไม่มีในระบบทดลอง และจะไม่ใส่ในช่วงทดลอง
- ใช้ได้เฉพาะตอนที่ Mac เปิดและต่อ Wi-Fi เดียวกัน

## ส่วนที่ 2 · แจกผู้ร่วมทดลอง

**Lighthouse Dispatch v2 — ทดลองใช้**

ระบบใหม่ที่จะมาแทนระบบเดิมในอนาคต วันนี้ขอให้ช่วยลองใช้และบอกว่าตรงไหนงง ขาด หรือผิด

**สิ่งที่ต้องรู้**
- ระบบเดิมยังเป็นระบบจริง ทำงานตามปกติต่อไป
- งานที่สร้างในระบบทดลองไม่ใช่งานจริง ลองได้เต็มที่ ไม่ต้องกลัวพัง
- ข้อมูลลูกค้าเป็นข้อมูลจริง **ห้ามถ่ายภาพหน้าจอหรือส่งต่อ**

**เข้าใช้งาน**
1. ต่อ Wi-Fi ของบริษัท
2. เปิดที่อยู่ที่เขียนบนกระดาน
3. ใส่ PIN ที่ได้ยินในที่ประชุม
4. เลือกบทบาทของคุณ

**ลองอะไรได้บ้าง**
| บทบาท | ลองทำ |
| --- | --- |
| ฝ่ายขาย | สร้างงาน ใส่อุปกรณ์และช่าง ลองตั้งราคาต่ำกว่าราคากลางแล้วดูว่าต้องให้ CEO ยืนยัน ย้ายเป็น Order และ Approve ดาวน์โหลดใบเสนอราคา |
| สโตร์ | หน้าสโตร์ (ของออก/ของเข้า 7 วัน) เช็กเอาต์และเช็กอินงานทดลอง ระบุของเสียหายแล้วส่งซ่อม แก้สต็อกในรายการอุปกรณ์ |
| บัญชี | เปิดงานที่คืนของแล้ว แก้ค่าประกันหรือส่วนลดเพิ่ม ย้ายเป็น Draft INV ดาวน์โหลด Draft INV |
| ผู้ดูแล / CEO | ห้องควบคุม ยืนยันราคาพิเศษ หน้าทีม |
| ดูแลช่าง | เรทช่าง ตรวจตำแหน่งและเรทที่คุณรู้จัก |

**บอกความเห็น**
- กดปุ่ม **ความเห็น** มุมขวาล่าง ได้ทุกหน้า
- เขียนสั้นๆ ว่าตรงไหนงง ขาด หรือผิด และ **ใส่ชื่อคุณด้วย**
- ระบบบันทึกให้เองว่าส่งจากหน้าไหน
